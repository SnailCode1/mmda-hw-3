### Запуск приложения

Версия Python: 3.11
Установите зависимости:
```bash
pip install -r requirements.txt
```

Запустите приложение:
```bash
streamlit run app.py
```

Приложение откроется в браузере по адресу `http://localhost:8501`.

### Ответы на вопросы

`st.cache_resource` используется для модели, поскольку она является ресурсом, который достаточно загрузить один раз и повторно использовать между запусками приложения и пользовательскими сессиями. Кэш возвращает один и тот же объект модели.

`st.cache_data` используется для таблиц (DataFrame), поскольку он предназначен для кэширования данных. При обращении к кэшу возвращается отдельная копия данных, что защищает их от случайного изменения другими пользователями.

Если вызвать joblib.load без декоратора, модель будет заново загружаться при каждом повторном выполнении скрипта Streamlit (например, при изменении порога или нажатии кнопки).
